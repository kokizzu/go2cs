a skipped test and not a tolerance. Each one is pinned by exact failure signature in the package's
hand-owned [`go2cs_test_disclosures.json`](https://github.com/ritchiecarroll/go2cs/blob/master/src/core/crypto/sha1/go2cs_test_disclosures.json);
